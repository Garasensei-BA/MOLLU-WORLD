# Blue Archive Future Sight Auto Update

GitHub에 올리면 GitHub Actions가 20분 간격으로 미래시 자료를 확인하고 future-data.json을 갱신합니다.

- 기본 범위: 4개월
- 선택 범위: 2/4/6/12개월
- 한국 서버 기준
- 몰루로그: 예상 일정
- 공식 커뮤니티: 공식 일정 확인
- 블아갤/아카라이브/루리웹: 커뮤니티 참고
- 충돌 상태: 의견 갈림
- 홈 배너: 자동 수정하지 않음
- 추천도: 추천/좋음/애매/굳이

주의: GitHub Actions는 예약 실행이 지연될 수 있습니다. 또한 사이트 HTML 구조가 바뀌면 수집 코드를 수정해야 합니다. 이 코드는 임의의 미래시를 만들어내지 않고 실제 웹페이지에서 확인 가능한 자료만 저장합니다.
